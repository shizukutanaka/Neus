# Competitive Advantage — Neus の競合優位性 (2026-11-22)

手法: 競合調査(有料・無料を問わない)→ お金の流れの分解 → マスク思考法+ソクラテス問答を、意味のある知見が出るまで反復。本書は日付つきの記録であり、価格は調査時点の公開情報に基づく。

## お金の流れの分解

利用者が払っているのは「読む機能」ではない。

1. **資産へのアクセス権の家賃** — ハイライト、タグ、学習済みの興味、裁決や履歴といった再作成できない資産は運営のデータベースの中にあり、月額を払い続ける限りアクセスできる。無料枠が意図的に狭い(Feedly 100ソース、Inoreader 150フィード、NewsBlur 64サイト)のは、資産が貯まるほど解約コストが上がる構造を作るため。
2. **AI 推論費** — クラウド勢は要約・選別の推論費を自社で負担し、上位プラン(Feedly Pro+ 等)で回収する。Neus は BYOK で、推論費は利用者自身の鍵と契約に乗る。
3. **運用の時間** — セルフホスト勢は金を取らない代わりに、サーバーの構築・更新・バックアップという利用者の時間を取る。

そして、この市場の実際の死に方は機能競争の敗北ではない。Pocket は Mozilla の判断で2025年7月に終了し、保存ライブラリは書き出し期限付きで削除された。Omnivore は2024年11月、チームの買収に伴い約2週間の猶予で終了した。**保管者が引退した日に、利用者の資産は一緒に消えた。**

## 反復の記録

### ラウンド1 — 「賢さ」と「無料」を疑う

- 疑った前提: 価値 = 集約の網羅性と AI 選別の賢さ。全社が同じ土俵におり、Neus も Watchword・興味学習・BYOK 要約で同じ方向を向いていた。
- 「無料が優位」→ 消えた。NetNewsWire と FreshRSS が既に無料で存在する。
- 「ローカルファーストが優位」→ 半分消えた。セルフホスト勢もデータは自己管理。ただし彼らはサーバーの運用を利用者に要求する。
- 生き残り: サーバー運用すら要らない形(端末内完結+ステートレスなプロキシのみ)での所有。BYOK(推論費は利用者の鍵)。Obsidian Vault への Markdown 直接書き出し。Watchword の探究(問い・反証条件・裁決の変遷)は他社に無い。

### ラウンド2 — 「保管者」を疑う(前提が崩れた)

- 削除テスト: 要約を消しても、興味学習を消しても、製品は立つ。
- 次に市場の死に方を実測した。Pocket と Omnivore の利用者は、機能に負けて去ったのではない。保管者が引退した日に、再作成できない資産ごと消えた。
- **崩れた前提**: 競合の本当の商品は「読む機能」ではなく「あなたの読書資産の保管とアクセス権」であり、その対価が月額だった。優位の所在は機能ではなく、資産の置き場所の設計にある。
- Neus には「終了する主体」が構造に存在しない。データは端末内にあり、書き出しは利用者のフォルダにある Markdown と JSON バックアップ。作成者が消えても、利用者の資産は1バイトも減らない。

## 構造的優位

Neus は、利用者の読書資産を預かる保管者を構造から排除した情報ハブであり続けられる。競合の収益は「資産へのアクセス権の月額販売」そのものであるため、資産を利用者の端末と利用者の Vault に最初から置く設計は、彼らの課金モデルを壊さずには真似できない。Neus は収益もサーバーも持たないため、その約束を無条件に、永続的に守れる。

## 残りの機会(順位つき)

1. **Pocket 書き出し(HTML/CSV)の取り込み** — 終了した保管サービスからの難民の入口。資産の置き場所という優位を獲得導線に変える本丸。現行の取り込みは OPML / 自前 JSON / 単発共有のみ。
2. **README 冒頭の看板を「終了しない保管」へ** — 「月額$0」の訴求は価格の話であり、無料の NetNewsWire 等と区別がつかない。優位は価格ではなく資産の置き場所にある。
3. **Readwise / Inoreader からのハイライト取り込み** — OPML は既存。ハイライトとメモの移行が揃えば乗り換えが完結する。
4. **Watchword の探究を README 冒頭へ** — 問い・反証監視は他社に無い差別化だが、機能一覧の中位に埋もれている。
