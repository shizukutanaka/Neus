# ADR-0010 — arXiv研究に基づくランキング/タグ改善

**Date**: 2026-05-30
**Status**: ACCEPTED (v0.4.0で部分実装)

## Context

arxiv.org からNeusの中核技術領域(興味モデリング/推薦、重複検知、オンデバイス処理)の最新研究を調査し、ゼロ依存・ローカルファースト・サーバーレス・買い切りの制約下で適用可能な知見を抽出した。

## 調査した研究と判断

### 採用

| 研究 | 知見 | Neusへの適用 |
|---|---|---|
| Lifetime-aware Interest Matching (CIKM'25, arxiv 2508.13064) | ニュースには「寿命」があり興味は時間減衰する | **Digest top3スコアに半減期6時間の指数減衰を導入** |
| IP2: Entity-Guided Interest Probing (RecSys'25, arxiv 2507.13622) | ニュースは固有名詞(エンティティ)が興味の核、時間依存的 | **TagLearnerにエンティティ抽出を追加(コールドスタート補完)** |

### 部分採用 / 将来

| 研究 | 知見 | 判断 |
|---|---|---|
| HieRec (ACL'21, arxiv 2106.04408) | トピック/サブトピック階層で興味表現 | キーワードの階層化は将来検討。現状はフラットなWATCH/BLOCKで十分 |
| WebLLM (arxiv 2412.15803) | WebGPUでブラウザ内LLM、ネイティブの最大80%性能 | ADR-0006(Bonsai 1.7B)の裏付け。オンデバイス要約はv1.1計画維持 |

### 却下(制約に反する)

| 研究 | 却下理由 |
|---|---|
| ニューラルCF / GCN推薦 (WWW'26) | サーバー学習・重いモデル前提。ローカルファースト制約に反する |
| LLM推論ベース推薦 (arxiv 2602.15005) | クラウドLLM依存。サーバーレス・プライバシー制約に反する |
| SimHash/MinHash近似重複検知 | 数万件規模で有効だが、現状の数百件規模ではJaccard(実測0.7ms)で十分。過剰最適化 |

## Decision

1. **時間減衰スコア**: Digest top3 ランキングに `25 * 0.5^(age/6h)` の鮮度ブーストを加算
2. **エンティティ抽出**: タイトルから英語固有名詞(大文字始まり連続語、ストップワード除去)とカタカナ語を抽出し、学習タグ不足時の自動タグ補完に使用

## Rationale

### 時間減衰を採用する理由
- 現状のtop3は `score + 要約20 + 未読10` で時間情報を無視
- 24時間以内でも6時間前と23時間前では「今読むべき」度が違う
- ゼロ依存・O(1)計算で実装でき、制約に完全合致
- CIKM'25の理論的裏付けあり

### エンティティ抽出を採用する理由
- TagLearnerはユーザーのタグ付け学習がベース → 初期(タグ未付与)はコールドスタートで機能しない
- エンティティ抽出は学習不要で初日から動く
- 正規表現ベースでゼロ依存・軽量
- IP2の「エンティティが興味の核」という知見と一致

### SimHashを却下する理由
- 現状のJaccard類似度は実測0.7ms(@1000件)で全く問題なし
- SimHashは数万〜数百万件規模でメモリ効率が効く技術
- 「測定なき最適化禁止」: 現状の規模では最適化が不要
- 短いタイトルではSimHashの誤判定リスク(低Hamming距離の区別困難)もある

## Consequences

- **+**: Digestの「今読むべき」精度向上(鮮度考慮)
- **+**: 初日からエンティティベースの自動タグが付く(コールドスタート解消)
- **+**: すべてゼロ依存・ローカル完結、制約に完全合致
- **-**: エンティティ抽出は正規表現ベースで言語依存(英語/日本語のみ。中韓は未対応)
- **-**: 時間減衰の半減期(6h)はハードコード。将来設定化の余地
